mindb

PostgreSQL client with a terminal-like UI and an AI query assistant.

llm: OpenAI · Anthropic · Kimi

View on GitHub Get started

Features

Terminal session

Dark, monospace transcript. Ask in plain language or prefix with sql: for direct queries.

Schema-aware AI

Tools for schema discovery, SQL execution, and explain plans — answers grounded in database evidence.

Persisted connections

Save profiles locally. Passwords and API keys stay in secure storage, not in the repo.

Safety by default

Read-only mode, write/destructive classification, LIMIT injection, and confirmation before risky SQL.
